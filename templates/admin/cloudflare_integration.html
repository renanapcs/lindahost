Como Configurar
1. Obter API Token
  1. Acesse o painel do Cloudflare
  2. Clique em "Create Token"
  3. Use o template "Custom token"
  4. Configure as permissões:
    • Account: Cloudflare Pages:Edit
    • Zone: Zone:Read, DNS:Edit
2. Obter Account ID
  1. No painel do Cloudflare
  2. Vá para "Overview"
  3. Copie o "Account ID" da barra lateral direita
3. Zone ID (Opcional)

Se você já tem uma zona DNS configurada, pode especificar o Zone ID padrão aqui.
