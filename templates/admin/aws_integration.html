Como Configurar
1. Criar Usuário IAM
  1. Acesse o IAM Console
  2. Vá para "Users" → "Create user"
  3. Adicione as políticas:
    • AmazonECS_FullAccess
    • AmazonVPCReadOnlyAccess
    • ElasticLoadBalancingFullAccess
2. Gerar Chaves de Acesso
  1. No usuário criado, vá para "Security credentials"
  2. Clique em "Create access key"
  3. Escolha "Application running outside AWS"
  4. Copie o Access Key ID e Secret Access Key
3. Configurar Região

Escolha a região mais próxima do Brasil (sa-east-1) para melhor performance.

4. Chaves SSH (Opcional)

Para deploy de containers, você pode configurar chaves SSH para acesso aos recursos AWS.
